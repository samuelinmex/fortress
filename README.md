# Fortress Smart Security — Web V1

Prototipo estático multipágina preparado para GitHub Pages.

## Páginas
- `index.html` — Inicio
- `hogar.html` — Hogar / pequeño negocio
- `empresas.html` — Empresas / proyectos
- `tecnologia.html` — Tecnología inteligente
- `nosotros.html` — Marca, misión y visión
- `cotizador.html` — Cotizador básico residencial

## Publicación rápida en GitHub Pages
1. Sube todos los archivos a la raíz de un repositorio.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Usa `main` y `/ (root)`.
5. Guarda.

El sitio usa rutas relativas, por lo que funciona también cuando GitHub Pages publica bajo `usuario.github.io/repositorio/`.

## Dependencias externas
- Google Fonts: Sora + Manrope.
- GSAP + ScrollTrigger por CDN en la página principal. Si el CDN no carga, el sitio conserva el contenido y animaciones básicas.
